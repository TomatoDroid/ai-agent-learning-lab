# 周报写作

## 读者与标准
读者是忙碌的直属主管，30 秒内要知道：做成了什么、卡在哪里、需要谁做什么。

## 核心原则
1. 先写结论，再写细节。反例：“本周主要围绕 A 项目展开了多项工作……”。正例：“A 项目上线，转化率 +3%”。
2. 每条进展都带可核验的证据（链接、数字或 PR 编号）。
3. 风险写清楚影响、应对和需要的支持。

## 禁止
- 不写“持续推进”“稳步进行”这类无信息量的词，除非后面跟着具体数字。

## 完成标准
三段：本周进展（≤5 条）、风险与求助、下周计划（≤3 条）。
