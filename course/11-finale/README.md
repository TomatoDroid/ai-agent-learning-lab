# 结业 · 回到公式

对应原书：[后记：回到 Agent = LLM + 上下文 + 工具](https://github.com/bojieli/ai-agent-book/blob/dbc046eb896ac4e39aa19c7774c8bf49583b89a6/book/afterword.md)

> **本模块正在编写中。** 下面是结业安排，现在就可以先读后记。

全书从一条公式开始，也在这条公式结束。结业不是新知识，而是把十章重新压回一页纸，并让 mini-agent 交出一份成绩单。

## 精读

后记全文（约 20 分钟），重点读 §两朵乌云 和 §模型与 Agent 的共同演进。读的时候对照 [0.1 课](../00-start/0.1-map.md)的三层解释（实现、直觉、学术），看看自己现在的理解多了什么。

## 结业任务

1. **一页纸**：不看资料，用一页纸重新解释 Agent = LLM + 上下文 + 工具。每一项写出它在全书中被展开成了哪些技术，以及你在 mini-agent 里亲手实现了哪些。
2. **成绩单**：用模块 7 建立的评估集，为最终版的 mini-agent 写一份评估报告：成功率、成本、典型失败和失败归因。
3. **路线图**：写一份“我会怎样改进它”的计划。每一条改进都要说明它属于上下文、工具、Harness、后训练还是持续进化，以及你会用什么评估证明它有效。

## 自测

回到 0.1 课的“读前问题”，再答一遍，对比第一次的答案。如果你能讲清“两朵乌云”各自指什么、为什么它们决定了 Agent 下一阶段的方向，这门课就算读完了。
