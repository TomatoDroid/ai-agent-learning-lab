# 深入理解 AI Agent · 实践课

这是一门陪你**读完并真正掌握**李博杰《深入理解 AI Agent：设计原理与工程实践》（2.0 版）的课程。
它不替代原书，而是给原书搭脚手架：带着问题精读，用动画看清机制，用代码亲手实现，用闭卷题检验自己。

> 全书一句话：**Agent = LLM + 上下文 + 工具**。生产形态下：**Agent = Model + Harness**。

## 这门课怎么学

每节课都按同一个节奏走：

| 环节 | 做什么 | 为什么 |
| --- | --- | --- |
| 读前 | 带着 2–3 个问题去读 | 有问题的阅读，记住的东西多得多 |
| 精读 | 读原书指定小节（链接到上游 2.0 原文） | 作者的论证和数据才是本体 |
| 拆解 | 看动画，理清机制和常见误解 | 有些机制用文字讲十遍不如看一遍 |
| 动手 | 在 `mini-agent` 里写体现原则的那几十行，跑测试验收 | 自己写出来，才算真的懂 |
| 检验 | 闭卷回答，再对照答案；做原书思考题 | 检索练习是最有效的记忆方法 |
| 复盘 | 一张“把书看薄”的卡片 | 一句话原则 + 适用边界 + 反例 |

原书作者的说法是：**先把书看薄，再把书看厚，再把书看薄**。精读是看厚，动手是看得更厚，复盘卡是重新看薄。

## 主线项目：mini-agent

贯穿全课的是一个你从零写出来的 Agent：[mini-agent](../mini-agent/README.md)。
第一章给它写出 ReAct 循环和护栏，第二章教它管理上下文（Chat Template、缓存友好、注入防御、Skills、状态栏、压缩），后面每章继续加能力。
所有检查点都用假模型测试，**不需要 API Key** 也能完成；有 Key 时可以接上真实模型对话。

## 三种深度

沿用原书作者在[学习建议](https://github.com/bojieli/ai-agent-book/blob/dbc046eb896ac4e39aa19c7774c8bf49583b89a6/docs/zh-CN/LEARNING.md)里的分层：

- **Starter（必修）**：精读 + 动画 + mini-agent 检查点 + 闭卷题。只需要 Python 和一台电脑。
- **Builder**：再跑原书的配套实验（需要 API Key，部分需要本地模型）。每课的“延伸”一节会指出该跑哪个。
- **Researcher**：复现需要 GPU、外部基准或硬件的实验（第 6、7、8、10 章较多）。
