## 你需要什么

原书“前置知识”一节列了四项必需：Python、LLM 使用经验、一款 AI 辅助编程工具、软件工程常识（命令行、Git、JSON、REST API）。
本课程的必修部分只需要其中的 Python 和命令行。**不需要 API Key**：所有检查点都用假模型测试。

作者特别推荐装一款 AI 编程工具（Claude Code、Codex、Cursor 等）。理由值得记住：这些工具本身就是成熟的 Coding Agent，你在用它们的时候，会直接体验到 ReAct 循环、工具调用和上下文管理。学到第一、二章时，不妨边用边观察它们的行为。

## 步骤

1. 克隆本课程仓库：

   ```sh
   git clone https://github.com/TomatoDroid/ai-agent-learning-lab.git
   cd ai-agent-learning-lab/mini-agent
   ```

2. 准备 Python 3.10 以上版本，安装 pytest：

   ```sh
   python -m pip install pytest
   ```

3. 先看参考答案跑起来是什么样子：

   ```sh
   cd solutions && python -m mini_agent demo && cd ..
   ```

   你会看到原书第一章“多币种收入汇总”那条轨迹：用户提问 → 模型并行调用 3 次换算 → 调用计算器 → 给出答案。最后一行打印了每次调用模型时读入的消息条数，比如 `[2, 6, 8]`。先猜猜为什么是这三个数，1.2 课会解释。

4. 运行练习版的测试：

   ```sh
   python -m pytest -q
   ```

   现在应该**全部失败**，失败信息里写着“练习 x.y 还没有完成”。每一个失败都是一道练习，后面的课会逐个带你完成。

5. （可选）想同时跑原书的配套实验，再克隆上游仓库：

   ```sh
   git clone https://github.com/bojieli/ai-agent-book.git
   ```

   上游实验按章节放在 `chapter1/` 到 `chapter10/`，用 uv 或 pip 按章安装依赖，详见上游 README 的“运行配套实验”。

## 练习怎么做

打开 `mini_agent/loop.py`，你会看到这样的段落：

```python
    # TODO 练习 1.2：实现 ReAct 循环
    # 提示：循环最多 max_iterations 次；每次先调用 before_call(messages)（如果有），
    # ...
    raise NotImplementedError("练习 1.2 还没有完成：实现 ReAct 循环")
```

把 `raise` 那一行换成你的实现，然后运行对应的检查点，比如 `python -m pytest tests/test_ch01_loop.py`，全部通过就算完成。

几条建议：

- **先自己写，卡住再看** `solutions/` 里的参考答案。
- 可以用 AI 编程工具帮忙，但**先自己说清楚要写什么**再让它写。作者在 FAQ 里说，配套代码都是 coding agent 写的，人负责设计和验收。这门课要练的正是“设计和验收”。
- 测试名都是中文，描述的是原书里的一条原则。读测试本身就是在复习。

## 检验

<details>
<summary>1. 为什么检查点用假模型（ScriptedLLM）而不是真实模型？</summary>

为了让测试**确定、可复现**：同样的输入永远得到同样的结果，不受模型随机性和服务可用性影响。我们要验证的是 Harness 的行为（循环、护栏、上下文管理），而不是模型的能力。这也是第七章评估思想的一个小例子：先控制住变量，才能判断改动的效果。
</details>

<details>
<summary>2. 原书为什么建议你装一款 AI 编程工具？</summary>

一是提高写实验代码的效率；二是这些工具本身就是成熟的 Coding Agent，使用它们能直接体验 ReAct 循环、工具调用和上下文管理。
</details>
