# 模块 0 · 开学

对应原书：[引言](https://github.com/bojieli/ai-agent-book/blob/dbc046eb896ac4e39aa19c7774c8bf49583b89a6/book/introduction.md)

这个模块做两件事：先在脑子里放一张全书地图，再把 mini-agent 跑起来。

| 课 | 内容 | 时长 |
| --- | --- | --- |
| [0.1 全书地图与学习方法](0.1-map.md) | 一条公式、两大部分、五个贯穿全书的设计模式 | 约 40 分钟 |
| [0.2 准备环境，跑通第一个 Agent](0.2-setup.md) | 装好 Python 和 pytest，看懂离线演示的轨迹 | 约 30 分钟 |

学完后你应该能：

- 用三种说法解释 Agent = LLM + 上下文 + 工具，并说清它**不包含**什么；
- 说出全书两大部分各自回答什么问题；
- 在本地运行 mini-agent 的测试，知道练习在哪里写、怎么验收。
