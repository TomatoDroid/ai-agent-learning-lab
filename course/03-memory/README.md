# 模块 3 · 用户记忆和知识库

对应原书：[第三章 用户记忆和知识库](https://github.com/bojieli/ai-agent-book/blob/dbc046eb896ac4e39aa19c7774c8bf49583b89a6/book/chapter3.md) · 原书配套实验：[chapter3/](https://github.com/bojieli/ai-agent-book/tree/dbc046eb896ac4e39aa19c7774c8bf49583b89a6/chapter3)

第二章管理的是**一次任务之内**的上下文。这一章要让 Agent 在对话结束后仍然记得：用户记忆让它记住“这个人”，知识库让它查到“这件事”。两者是同一个问题的两个尺度，共用检索技术，也共有同样的麻烦：信息冲突、知识过期、检索不准，以及检索回来的内容同样可能是注入通道。

| [3.2 RAG 基础](3.2-rag-basics.md) | §RAG 基础（全节） | 练习 3.2：分块、BM25、RRF、评测指标 | 约 100 分钟 |
| [3.3 超越扁平文本与 Agentic RAG](3.3-agentic-rag.md) | §超越扁平文本（全节）、本章小结 | 练习 3.3：上下文前缀、检索层过滤、检索工具 | 约 110 分钟 |

学完后你应该能：

- 用三层次框架评估一个记忆系统，并为不同信息选择存储格式；
- 解释为什么“只追加、使用时判断”比“写入时覆盖”更安全；
- 手算 BM25，说清稠密和稀疏检索各自的盲区，以及 RRF 和重排序各做什么；
- 判断什么时候需要结构化索引，设计一条“知识即代码”的更新流程；
- 把检索做成工具，并在检索层处理失效、权限和注入。
